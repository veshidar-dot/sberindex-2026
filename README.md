# СберИндекс 2026: прогноз расходов МО и ранняя детекция структурных сдвигов

Работа в номинации «Прогнозирование» онлайн-конкурса СберИндекса.

- Методологический отчёт: [`docs/report.md`](docs/report.md)
- Интерактивный лендинг: https://veshidar-dot.github.io/sberindex-2026/ (исходник - `landing/`)

## Результат

| MAE, руб. на жителя в месяц | h = 1 | h = 3 | h = 6 | h = 12 |
|---|---|---|---|---|
| **Ансамбль** (5 моделей на одном разложении) | **313** | **461** | **548** | **607** |
| Prophet (базовая модель конкурса) | 606 | 642 | 764 | 922 |
| Prophet + сезонный профиль национального ряда (вторая база) | 522 | 733 | 856 | 1 178 |
| Наивная (последнее значение) | 678 | 843 | 1 057 | 1 403 |

Скользящее начало прогноза 2023-12 ... 2024-11, все 2190 МО и 6 категорий. Ансамбль точнее Prophet на
48 / 28 / 28 / 34 %, лучшей из двух баз на каждом горизонте - на 40 / 28 / 28 / 34 % (тест Диболда-Мариано: p <= 0.01
везде, кроме h = 3 против обычного Prophet, p = 0.07); R² 0.994-0.997. Лучший детектор сдвигов - LR-тест ступеньки в уровне внутри той же
модели, в двух каналах (сам ряд и ряд относительно соседей по дорогам): при 5 % ложных тревог находит 47 % вставленных
сдвигов (с новостями; BOCPD - 34 %, CUSUM - 11 %), в среднем в тот же месяц.

Лучшая модель выбрана процедурой: набор лучших моделей (MCS) на каждом горизонте и сведение 24 ранжирований
«горизонт x категория» правилами Борда, Коупленда, Кемени и пороговым - ансамбль первый при всех четырёх и
побеждает каждую модель в парном сравнении. В определении «средняя ошибка по шагам 1…H на 12 096 полных рядах»,
которым пользуются другие работы конкурса, ансамбль даёт 306 / 380 / 445 / 484 руб. против 599.5 / 566.2 / 592.5 /
894.3 у Prophet. Прогноз общей траектории проверен вне выборки на национальном ряде 2025-2026 гг.; прогноз МО на
2025 г. заморожен с SHA-256: [`forecast_2025/`](forecast_2025/).

## Идея в трёх строках

1. Лог расходов МО раскладывается на общую траекторию категории и локальную часть МО:
   `log y_it = n_ct + z_it`. Основную ошибку даёт общая часть, поэтому её прогнозируем по длинному
   национальному ряду СберИндекса «Потребительские расходы» (с 2018 г.): у панели всего 24 месяца.
2. Локальную часть прогнозируют пять моделей: модель пространства состояний (случайное блуждание уровня +
   AR(1), ММП фильтром Калмана по всей панели), сезонный профиль МО, LightGBM с соседями по графу дорог,
   TimesFM 2.5 и Chronos-2 без дообучения. Итог - их среднее в логах.
3. Структурный сдвиг - ступенька в уровне; детектор - LR-тест ступеньки в той же модели.
   Проверенные события по МО повышают априорную вероятность сдвига.

## Установка

Нужен Python 3.12 (prophet, ruptures и torch пока не собираются под 3.14).

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv --extra-index-url https://download.pytorch.org/whl/cpu --index-strategy unsafe-best-match -r requirements.txt
```

Данные конкурса не хранятся в репозитории. Скачайте `hackathonlicence.zip` со страницы конкурса и
распакуйте в `data/`, чтобы получилось `data/hackathonlicence/consumption.parquet` и т. д. Другой путь
можно задать в `config.local.yaml` (не в git):

```yaml
data:
  dir: D:/path/to/hackathonlicence
output_dir: D:/path/to/out
```

## Запуск

Всё одной командой:

```bash
python -m sbi.run_all
```

Около 6 часов на 16-ядерном CPU, из них Prophet ~3.5 ч (13 140 рядов x 12 точек начала), TimesFM 2.5 и
Chronos-2 по 10-15 мин на вариант. Веса `amazon/chronos-2` и `google/timesfm-2.5-200m-pytorch` (~800 МБ)
скачиваются с Hugging Face при первом запуске. `--skip-existing` не пересчитывает готовые прогнозы.

По шагам:

```bash
python -m sbi.forecast --models panel_ssm prophet   # прогнозы выбранных моделей -> out/forecasts
python -m sbi.report                                # MAE, R2, WAPE, тест Диболда-Мариано -> out/metrics.csv, out/tables.md
python -m sbi.ablation                              # вклад общей траектории: правила и «оракул»
python -m sbi.detect_eval                           # детекторы на вставленных сдвигах
python -m sbi.detect_real                           # детекторы на реальных событиях
python -m sbi.gdelt                                 # новости GDELT: опережение и детектор с новостями
python -m sbi.news_eval                             # эффект новостей на прогноз
python -m sbi.studies                               # регион и модель роста (отвергнутые гипотезы)
python -m sbi.selection                             # выбор лучшей: набор лучших моделей (MCS), сведение ранжирований
python -m sbi.national_oos                          # общая траектория вне выборки: национальный ряд 2025-2026 гг.
python -m sbi.forward                               # замороженный прогноз на 2025 г. от декабря 2024 г. + SHA-256
python -m sbi.export_landing                        # данные для лендинга
```

Тесты (в том числе «без заглядывания вперёд»: порча данных после точки начала не меняет прогноз):

```bash
python -m pytest -q tests
```

## Конфигурация

Все пути и гиперпараметры - в `config.yaml`: схема проверки (точки начала, горизонты), параметры каждой
модели, состав ансамбля, детекторы, синтетический эксперимент, новости. Случайность фиксирована (`seed: 42`).

## Структура

| Файл | Что делает |
|---|---|
| `sbi/data.py` | панель (МО x категория) x месяц |
| `sbi/national.py` | прогноз общей траектории категории по национальному ряду СберИндекса |
| `sbi/models/panel_ssm.py` | центральная модель: фильтр Калмана по панели, ММП |
| `sbi/models/panel_seasonal.py` | разложение с собственной сезонностью МО |
| `sbi/models/lgbm.py` | LightGBM на панели (соседи по дорогам; вариант с новостями GDELT) |
| `sbi/models/fm_local.py` | TimesFM 2.5 и Chronos-2 на локальной компоненте; TimesFM по сырым рядам |
| `sbi/models/chronos_fm.py` | Chronos-2 по сырым рядам, в том числе cross-learning |
| `sbi/models/ensemble.py` | итоговый ансамбль |
| `sbi/models/baselines.py` | наивная, сезонная наивная, Prophet (базовая модель конкурса) |
| `sbi/news.py` | каталог событий, объединение реестров, матрица «вероятности сдвига» без заглядывания вперёд |
| `sbi/gdelt.py` | поток новостей GDELT по МО: «МО - регион», неожиданность новостей, проверка опережения |
| `sbi/detect.py` | детекторы: CUSUM, PELT, BOCPD, LR-тест в модели пространства состояний |
| `sbi/detect_eval.py`, `sbi/detect_real.py` | сравнение детекторов на синтетике и на реальных событиях |
| `sbi/evaluate.py`, `sbi/report.py` | метрики, тест Диболда-Мариано, таблицы для отчёта |
| `sbi/studies.py` | проверенные и отвергнутые гипотезы: региональная компонента, модель роста с ключевой ставкой |
| `sbi/selection.py` | выбор лучшей модели и детектора: набор лучших моделей (MCS), правила Борда, Коупленда, Кемени, пороговое |
| `sbi/national_oos.py` | правила общей траектории на национальном ряде 2025-2026 гг. (вне выборки) против Prophet |
| `sbi/forward.py` | прогноз ансамбля на 2025 г. от последнего месяца панели, манифест с SHA-256 |
| `sbi/run_all.py` | полный прогон |
| `tests/` | проверки отсутствия утечки будущего |

## Данные третьих сторон

- `ref/mo_names.csv` - справочник «territory_id - название МО» из метаданных датасета СберИндекса
  «Потребительские безналичные расходы на уровне муниципальных образований»;
- `ref/consumer_spending_national.csv` - датасет СберИндекса «Потребительские расходы» (РФ, млрд руб. в месяц).
- `ref/key_rate.csv` - датасет «Ключевая ставка в реальном выражении» (ключевая ставка, реальная ставка, базовая
  инфляция за 3 мес.; на сайте СберИндекса, источник указан как ЦМИ), скачан 08.10.2026.
  Источник - https://sberindex.ru, лицензия CC BY-SA 4.0 (данные скачаны 07-08.10.2026).
- `ref/events.csv` - наш каталог событий по открытым источникам (указаны в файле);
  `ref/events_merged.csv` - он же вместе с проверенными событиями реестра maloyan (собирается `python -m sbi.news`).
- `ref/news/` - агрегаты GDELT по МО и регионам и реестры событий из открытых репозиториев участников
  maloyan/sberindex-2026-forecasting и rav11l/sberindex-shocks (лицензия MIT; коммиты, проверка привязки и
  тексты лицензий - в `ref/news/SOURCES.md`).
