# СберИндекс 2026: прогнозирование расходов МО и структурные сдвиги

Работа в номинации «Прогнозирование» онлайн-конкурса СберИндекса.

## Данные

Данные не хранятся в репозитории. Скачайте архив `hackathonlicence.zip` со страницы конкурса
и распакуйте в `data/`, чтобы получилось `data/hackathonlicence/consumption.parquet` и т. д.

```bash
pip install pandas pyarrow numpy
python src/eda_decomposition.py
```
