# Замороженный прогноз на 2025 год

Прогноз итогового ансамбля (5 моделей на одном разложении, те же параметры, что в проверке) от последнего месяца
панели - декабря 2024 г. - на 12 месяцев 2025 г. Построен командой `python -m sbi.forward` и больше не меняется:
его можно сверить с данными МО за 2025 г., когда СберИндекс их опубликует.

- `ensemble_2025.csv.gz` - столбцы `territory_id`, `category`, `month` (2025-01 ... 2025-12), `forecast`
  (руб. на жителя в месяц); 157 680 строк, все ряды «МО x категория», у которых есть история.
- `manifest.json` - точка начала, состав ансамбля, число строк, SHA-256 файла и время построения.

Проверка, что файл не менялся:

```bash
sha256sum forecast_2025/ensemble_2025.csv.gz   # должно совпасть с sha256 в manifest.json
```

Прогноз построен по данным СберИндекса «Потребительские безналичные расходы на уровне муниципальных образований»
(CC BY-SA 4.0) и распространяется на тех же условиях.
